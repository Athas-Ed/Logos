## 9. 多会话执行手册（与归档 §12 对齐）

1. **每会话一条分支**，勿多 Agent 共 `--force` 同一远程分支。  
2. **推荐并行组合**：**会话 U** = A3（`src/gui`、`api_v1` 中 bootstrap、config）；**会话 K** = A4（`persistence`）。  
3. **A5 单独会话**或在 A4 merge 后由同一人续写，减少 `persistence/` 冲突。  
4. **A8a** 建议独立会话：专注 `tests/`、`run_backend_stub`、`harness` 装配。  
5. **合并前**：`pytest`；若动 MCP，跑 MCP 集成与进程泄漏相关测。
