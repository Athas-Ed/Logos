KSFS：每一层文件夹维护一份目录文件，不遗漏地记录当前目录下的每一个文件与文件夹的介绍性内容。每一个实体的文件（xxx.md）头部用 YAML 写元数据，同时记录 relations（target + type），为知识图谱功能做准备。

HSI：首要职责是维护索引缓存，自动分配实体id、记录实体名、确定性标签（type）、提示性标签（tags）、文件路径、面包屑路径、relations、自身的简介（来自md文件头部）、组装后的路径简介（来自一路上的目录文件），同时记录 KSFS 中文件哈希与变更时间，以便快速判断哪个文件被改过、需要更新 SVS 与 KG。
