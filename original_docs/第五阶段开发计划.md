1. 新功能必须挂 **Skill / `skill_id`**，不要继续加厚「无 Skill 的万能 Chat」。

## 2. 阶段目标（一句话）

在第四阶段 **G1～G4** 与 Electron 底座之上，把 Logos 从「**默认万能 Chat + 全工具 ReAct**」改为「**技能面板 → 选 Skill → 输入 → 按 manifest 范式执行 → 任务结束可归档**」。

### 2.1 必须交付

| # | 交付物 |
|---|--------|
| 1 | **技能面板**为首页（`/`），冷启动不再直达空白 Chat |
| 2 | **产品 Skill 框架**：manifest 注册、`skill_id` 请求、scoped tools、`schema_version: 2` 任务字段 |
| 3 | **PR 初开发**：`dialogue` + `react` 分轨；`plan` Phase A 可选；`pipeline` 不误入 ReAct |
| 4 | **竖切片 Skill**：`lint_zh`（dialogue+P2）、`chat_inspire`（dialogue+multi） |
| 5 | **契约**：`POST /chat` 含 `skill_id`；`bootstrap.skills[]` 供面板 |

### 2.2 明确顺延（本阶段不验收）

| 项 | 说明 |
|----|------|
| G5 `/cache` 全功能、启动占用提醒 | 顺延 **F5 后** |
| M-UI 视觉定稿 | 顺延；仅任务向导占位样式 |
| `pipeline` + 设定导入全链 | 下阶段 / A6 |
| PR `paradigm_auto` 智能推断 | 远期 |
| Electron 安装包、签名、真壳 E2E 全覆盖 | **`产品化文档.md`** |
