# 会话与任务缓存

## 档 B：本地任务 JSON

进行中的写作任务以 JSON 文件持久化在 **`paths.CONVERSATIONS_CACHE`** 所指目录（bootstrap 返回绝对路径 `conversations_cache_root`）。由 **Electron 主进程** 经 IPC 读写，渲染进程不直接碰盘。

**产品语义**：一个任务 = 一份会话 JSON；顶栏标签 = 打开中的任务槽。

## 状态生命周期

| 状态 | 含义 | 顶栏标签 |
|------|------|----------|
| `idle` | 进行中 | 显示 |
| `archived` | 已归档 | 从顶栏移除，可在 `/cache` 管理 |

- **归档**：用户结束任务后写入 `archived`，并取消进行中的防抖写盘，避免竞态把状态写回 `idle`。
- **恢复 / 销毁**：在缓存页操作，对应 IPC `read` / `write` / `destroy`。

冷启动时通常只恢复 `idle` 任务到标签栏；**无进行中任务时顶栏可为空**，不强制创建默认聊天标签。

## 前端核心模块

| 模块 | 路径 |
|------|------|
| 全局状态 | `src/gui/src/conversation/ConversationProvider.tsx` |
| 防抖写盘 | `persistScheduler.ts` |
| 磁盘记录 | `record.ts`、`createEmptyConversation.ts` |
| IPC 封装 | `conversation/ipc.ts` |
| 顶栏 | `components/TabBar.tsx` |
| 缓存页 | `pages/CachePage.tsx` |

## SSE 与多任务

- 并发 SSE 受 `ui.SSE_maxNum` 限制，超额请求排队。
- 会话缓存总大小超过 `ui.cache_warn_bytes` 时，GUI 可展示启动提醒（用户可关闭提示）。

## 与 KSFS（档 C）的边界

- 档 B 保存**任务过程**（消息、Skill 元数据、执行轨迹等）。
- **落户到 KSFS** 须走设定导入、晋升 API/CLI 或专用持久化 Skill，**不**把 JSON 缓存当作叙事实体事实源。
