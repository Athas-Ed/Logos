# 会话缓存（档 B）

> **用语**：对外统一称 **会话（Conversation）**。**任务（Task）** 与其 **1:1 同义**——一条会话 JSON 即用户完成一次 Skill 工作单元的全部状态；代码中保留 `task_input`、`/task/:id` 等字段名表意「有界工作」，见 [术语表 · §5](../术语表.md#5-gui会话与缓存)。

## 档 B：本地会话 JSON

进行中的写作**会话**以 JSON 持久化在 **`paths.CONVERSATIONS_CACHE`** 所指目录（bootstrap 返回 `conversations_cache_root`）。由 **Electron 主进程** 经 IPC 读写，渲染进程不直接碰盘。

**产品语义**：

- **一个会话 = 一次 Skill 任务**（同一 `id`、同一文件）。
- **不是** 一对多或多对多：顶栏每个标签对应**唯一** `conversationId`。
- 顶栏标签 = 打开中的会话槽。

## 状态生命周期

| 状态 | 含义 | 顶栏标签 |
|------|------|----------|
| `idle` | 进行中 | 显示 |
| `archived` | 已归档 | 从顶栏移除，可在 `/cache` 管理 |

- **归档**：用户结束会话后写入 `archived`，并取消进行中的防抖写盘，避免竞态把状态写回 `idle`。
- **恢复 / 销毁**：在缓存页操作，对应 IPC `read` / `write` / `destroy`。

冷启动时通常只恢复 `idle` 会话到标签栏；**无进行中会话时顶栏可为空**，不强制创建默认聊天标签。

## 档 B 记录（schema v3）

现行 JSON 含 `schema_version: 3`，除 `messages` 外按**轮次**归档：

| 字段 | 说明 |
|------|------|
| `citation_turns` | 每轮检索引用 `CitationItem[][]` |
| `tool_trace_turns` | 每轮 ReAct 工具轨迹摘要 `string[][]` |
| `react_step_limit_turns` | 每轮 ReAct 步数触顶 `{ hit: boolean }[]`（与 user 问题一一对应） |

内存态与磁盘对齐；读入旧会话若无 `react_step_limit_turns`，可由 assistant 正文中的历史内联触顶文案推断 `hit`。

## SSE 与多会话

- 并发 SSE 受 `ui.SSE_maxNum` 限制，超额请求排队。
- 会话缓存总大小超过 `ui.cache_warn_bytes` 时，GUI 可展示启动提醒（用户可关闭提示）。

## 与 KSFS（档 C）的边界

- 档 B 保存**会话过程**（消息、Skill 元数据、执行轨迹等）。
- **落户到 KSFS** 须走设定导入、晋升 API/CLI 或专用持久化 Skill，**不**把 JSON 缓存当作叙事实体事实源。
