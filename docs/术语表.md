# 术语表（Glossary）

Logos 对外文档与架构说明的统一用语。实现细节、排期与定案草稿见本机 `original_docs/`（不入库）。

---

## 1. 系统与角色

| 术语 | 英文 / 代码 | 含义 |
|------|-------------|------|
| **Logos** | — | 面向游戏叙事的本地写作 Agent。 |
| **Agent** | `src/logos/agent/` | **Agent 决策层**：编排与上下文，含 Agent 调度器、CB、PR。 |
| **Agent 调度器** | Shell（`shell.py`） | 任务执行入口；经**端口**调用检索、模型等。对外请称 **Agent 调度器**，避免单独使用 Shell。 |
| **OM** | `operating_mode` | **运行模式**：`author` / `director` 等，`director`暂未开发。 |
| **Pd** | `presentation` | **展示档位**：`work`（≈ WM）与 `developer`；与 OM、Obs **日志**正交；**不**决定是否在 GUI 暴露全文推理（见 §5.1）。 |

---

## 2. Agent 组件与执行范式

| 术语 | 英文 / 代码 | 含义 |
|------|-------------|------|
| **CB** | Context Builder | **上下文构建器**（context engineering）。 |
| **PR** | Paradigm Router | **范式路由器**；读取 manifest 的 `paradigm`。 |
| **执行范式** | `paradigm` | Agent **执行策略**（非 GoF 设计模式泛指）。 |
| **对话范式** | `dialogue` | 自由文本；非 ReAct JSON。 |
| **ReAct 范式** | `react` | 结构化 JSON 轮次 + 工具。 |
| **ReAct 步数上限** | `agent.react.max_steps` / `max_QA_steps` | 单轮 ReAct 内 LLM 迭代次数上限；`retrieve_qa` 用 `max_QA_steps` 且按 **每个 user 问题** 计数。 |
| **步数触顶** | `hit_step_limit` / `react_hit_step_limit` | 达上限后 synthesis 收束；GUI 展示说明条，检索问答下再发送则**新开会话**。 |
| **Plan 范式** | `plan` | 先计划再分步（Phase A 已落地，面板默认隐藏 `panel_visible: false`）。 |
| **Pipeline 范式** | `pipeline` | 确定性阶段表，非 ReAct 循环。 |

## 3. Skill 与基础设施

| 术语 | 英文 / 代码 | 含义 |
|------|-------------|------|
| **产品 Skill** | `skill_id` | 用户可选的任务配方，实现某一具体功能。 |
| **工具 Skill** | Tool Provider | 提供可调用的基础工具（MCP 或 `logos.tools`）。 |
| **Manifest 字段** | `paradigm` / `persistence_tier` / `turn_policy` / `allowed_tools` / `prompt_runtime_key` | Skill YAML 声明：执行范式、持久化档位、单/多轮策略、工具白名单、Prompt 运行时键。 |
| **`turn_policy`** | `single` / `multi` | 单轮（一次输入→一次输出）vs 多轮（同一会话内连续对话，如 `chat_inspire`）。 |
| **`prompt_runtime_key`** | `skills/<id>` | CB 加载 Skill 专属 Prompt 模板的键，对应 `resources/prompts/skills/<id>.md`。 |
| **`pipeline_profile`** | `your_profile_v1` | Pipeline 范式下的流水线配置标识，指向 `resources/entity_template/<profile>/` 下的配置。 |
| **基础设施层** | `infrastructure/` | Retrieval、MS、嵌入等全局能力。 |
| **能力层** | `skills/` | MCP 与 manifest。 |
| **持久化档位** | `p0` / `p1` / `p2` | 按「交流强度 × 文件操作强度」划分，与执行范式正交。见下方分类。 |
| **P0 — 流水线型** | `p0` | 低交流 + 高文件操作；粘贴即处理，全自动落盘。当前仅 `import_setting`。 |
| **P1 — 协作创作型** | `p1` | 中交流 + 中文件操作；需与用户讨论、确认后写盘。`setting_write`、`draft_review`。 |
| **P2 — 对话型** | `p2` | 高交流 + 低/无文件操作；产出在聊天消息中完成。`chat_inspire`、`lint_zh`、`retrieve_qa`。 |

## 4. 数据与持久化

| 术语 | 英文 / 代码 | 含义 |
|------|------|------|
| **KSFS** | knowledge source file system | 叙事知识唯一事实源（Markdown 文件树 + YAML front matter）。 |
| **HDL** | Hybrid Data Layer | 混合数据层（非硬件 HDL）；HSI + SVS + Sparse 三轨，均由 KSFS 构建。 |
| **HSI** | High-Speed Index | SQLite 元数据索引（路径、title 子串弱匹配）；零依赖，无 embedding 也可用。 |
| **SVS** | Semantic Vector Store | ChromaDB 语义向量库（bge-small-zh）；分块级语义近似检索。 |
| **Sparse** | `sparse_fts.py` | SQLite FTS5 全文索引；**分块级关键词精确命中**，专为专有名词（人名/地名/物品名）设计。见 `sparse_fts.py`。 |
| **FRS** | FusedRetrievalService | `infrastructure/retrieval/fused.py`；三路召回后按 path 去重取 max score 排序的融合检索服务。 |
| **KG** | knowledge graph | CozoDB（SQLite 后端）知识图谱；数据层已实现（entity/relation/entity_id 三表），`kg_query` Agent 工具已注册，融合未接入。 |
| **Setting Entry** | — | `workspace/setting_entry/` 待晋升草稿。 |
| **Entity Template** | — | `resources/entity_template/<profile>/`；JSON Schema、渲染规格、manifest.yaml，约束实体文件形态，与 Prompt、KSFS 用户文件三分离。 |

## 5. GUI、会话与缓存

| 术语 | 含义 |
|------|------|
| **会话** | **对外首选统称**；档 B 一条 JSON = 一次 Skill 工作单元。 |
| **任务** | 与**会话 1:1 同义**；代码保留 `task_*`、路由 `/task/:id`。 |
| **档 B / 档 C** | 档 B = 会话缓存（`workspace/conversations/*.json`）；档 C = KSFS 升格轨（草稿晋升至 KSFS 后成为事实源）。 |

---

## 6. 支撑层（Platform layer）

| 术语 | 英文 / 代码 | 含义 |
|------|-------------|------|
| **支撑层** | `logos.platform` | `src/logos/platform/`：I&I、S&G、Obs、Config。 |
| **I&I** | Interface&Integration`platform/ii_layer/` | HTTP/SSE、组合根装配。 |
| **S&G** | Security&Governance：`platform/sg_layer/` | 沙箱、工具白名单、输出治理、MCP 治理。 |
| **Obs** | `platform/obs/` | 日志；维护轨含 `platform.log` 等。 |
| **端口** | `ports/` | Retrieval、Metadata、Vector、Sparse 等端口抽象。 |

## 7. 协议与开发工具

| 术语 | 含义 |
|------|------|
| **MCP / SSE** | 见行业通用定义。 |
| **`paradigm_override`** | API 请求体可选字段；强制 PR 切换范式（dialogue/react/plan/pipeline）；仅 `developer.show_dev_tools_ui` 或 `LOGOS_FORCE_STUB_LLM=1` 时生效。 |
| **开发用组合根后端** | **Development backend** | 由 `scripts/run_dev_backend.py` 启动的本地 FastAPI（`:8000`）：装配 `AppPorts`、真实或桩 LLM、检索与 MCP。无 API Key 时 LLM 为内存桩（回复前缀「桩后端」）；**不是**与生产对立的「假服务」。 |
