# 架构概览

## 分层模型

Logos 采用自上而下、**端口（ports）隔离实现**的分层结构：

```text
┌─────────────────────────────────────────┐
│  GUI / Electron（会话、设置、缓存页）      │
└──────────────────┬──────────────────────┘
                   │ HTTP + SSE
┌──────────────────▼──────────────────────┐
│  支撑层 · I&I（`logos.platform`）         │
│  api_v1、组合根装配                       │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│  Agent 决策层：调度器 · CB · PR           │
└──────┬───────────────────────┬──────────┘
       │                       │
┌──────▼──────┐         ┌──────▼──────────────┐
│ Skills(MCP) │         │ Infrastructure      │
└─────────────┘         └──────┬──────────────┘
                               │
                        ┌──────▼──────────────┐
                        │ HDL：KSFS · HSI · SVS│
                        └─────────────────────┘
```

| 层 | 目录（典型） | 职责 |
|----|--------------|------|
| **Agent 决策层** | `src/logos/agent/` | Agent 调度器（Shell）、CB、PR |
| **能力层** | `skills/` | 产品 Skill manifest 与 MCP |
| **基础设施层** | `src/logos/infrastructure/` | 检索、模型服务等 |
| **持久层** | `src/logos/persistence/` | KSFS、HSI/SVS |
| **支撑层（PL）** | `src/logos/platform/` | I&I、S&G、Obs、Config |
| **端口** | `src/logos/ports/` | 抽象接口 |

> 支撑层包名 **`logos.platform`**（Platform layer）。与 OpenAI「Harness Engineering」、HashiCorp Harness CI **均不同**，见 [术语表 §9](术语表.md#9-行业对照)。

## 三种「数据地盘」

| 地盘 | 配置 / 路径 | 角色 |
|------|-------------|------|
| **KSFS** | `paths.ksfs_root` | 叙事实体唯一事实源 |
| **工作区** | `workspace/` | 草稿、`setting_entry/`、会话 JSON |
| **索引** | `.index/` | HSI、Chroma（可重建） |

## 仓库目录（精选）

```text
Logos/
├── src/logos/          # agent / platform / infrastructure / persistence / ports
├── src/gui/            # React 前端
├── src/electron/       # 桌面壳
├── skills/
├── config/
├── resources/          # ksfs/ 仅 README 入库
├── example_ksfs/       # 本机示例，不入库
├── docs/
├── scripts/            # run_dev_backend.py = 开发用组合根后端
├── workspace/          # 内容不入库
└── .index/
```

## 典型请求路径

1. 用户在 GUI 选择 Skill（开启或继续一条**会话**）。
2. `POST /api/v1/chat`（SSE）。
3. **I&I** 装配 `AppPorts` → **PR** → **Agent 调度器**（dialogue / react / pipeline 等）。
4. 检索经 Infrastructure + HDL；CB 拼装上下文。
5. 按 **Pd** 裁剪 SSE；会话写入档 B。
