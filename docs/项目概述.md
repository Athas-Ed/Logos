# 项目概述

## Logos 是什么

**Logos** 是一款面向**游戏叙事创作**的本地智能写作助手，目标用户为文案与叙事策划。系统在「作家 / 编剧」两种运行模式下工作，通过 **Skill（技能）** 组织具体能力，而不是默认提供无边界的多轮 Agent 聊天。

核心思路：

- **叙事知识**以文件树 **KSFS** 为唯一事实源，配合元数据索引（HSI）与向量检索（SVS）。
- **任务驱动界面**：用户从技能面板选择能力 → 输入 → 执行；长对话是其中一种 Skill，而非默认首页。
- **桌面形态**：Electron 壳 + React GUI，后端提供 HTTP 与 SSE；大模型走 OpenAI 兼容 API。

## 当前成熟度

本项目处于**活跃开发**阶段，API 与目录可能变动。仓库公开主要为备份与展示，**不承诺**开箱即用或长期兼容。使用前请阅读 [快速开始](快速开始.md) 并自行配置 `config/local.yaml`。

## 能力边界（对外说明）

| 已具备（概要） | 规划中或有限 |
|----------------|--------------|
| 会话 / Skill 驱动 GUI、多标签会话槽 | 知识图谱（KG）仅为预留 |
| KSFS + HSI/SVS 检索管线 | 部分范式（plan 等）仍在演进 |
| MCP 可插拔技能（如地图、示例 echo） | 多用户 / 多进程部署非目标 |
| 设定导入 Pipeline、草稿晋升至 KSFS | 完整「作品级」持久化轨仍在扩展 |
| OpenAI 兼容远程 LLM | 本地大模型为远期方向 |

## 技术栈摘要

- **后端**：Python 3.11+，`logos` 包（Agent 决策层、HDL、支撑层）
- **前端**：TypeScript、React、Vite（`src/gui/`）
- **桌面**：Electron（`src/electron/`）
- **协议**：REST + Server-Sent Events（`/api/v1`）
