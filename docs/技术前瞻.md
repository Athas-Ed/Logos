# Logos — 技术前瞻

> 面向面试官。展示项目的技术视野、可扩展方向和工程规划能力。
> 实现细节与个人笔记见 `original_docs/技术前瞻.md`（作者本机，不入库）。

---

## 一、检索质量深化

| 方向 | 说明 |
|------|------|
| **RRF 混合排序** | 将当前三路取 max 升级为 Rank 级融合，解决分数尺度不一致问题 |
| **Cross-Encoder 二次精排** | 召回后经交叉编码器重排序，压缩置信 Top-K |
| **Query 工程（HyDE / Multi-query）** | Agent 检索前先改写/扩展 query，提升召回质量 |
| **BM25 + FTS5 混合加权** | 引入 BM25 算法权重，替代 FTS5 默认评分 |

## 二、Agent 范式与编排

| 方向 | 说明 |
|------|------|
| **Plan 范式 Phase B** | 当前 stop-after-Plan，下一步支持按计划逐步执行 |
| **`paradigm_auto` 智能推断** | manifest 不写死范式时 PR 根据输入自动匹配 |
| **CD-4：Runner 插件化** | 新范式注册即用，无需修改 Shell 调度代码 |
| **HITL 审查节点** | pipeline 中插入人在回路确认步，当前流程纯自动 |
| **Agent 调用链可视化** | GUI 回放 ReAct / Pipeline 推理轨迹，展示可观测性 |

## 三、产品级 Skill 生态

| 方向 | 说明 |
|------|------|
| **`outline_plan` 产品定稿** | 6 个待定产品问题定稿后恢复开发 |
| **`ksfs_edit` 编辑 Skill** | 检索→提案→确认→写入 KSFS 的闭环写作 |
| **P0 灵感库落地选型** | 从候选方向中选 1-2 个验证 MVP |
| **Skill 组合与互调** | 一个 Skill 完成后自动触发下游 Skill |
| **动态表单** | GUI 根据 manifest `input_schema` 自动生成参数控件 |
| **冲突检测与解决 UI** | 重叠检测结果引入 GUI，可视化选择合并策略 |

## 四、产品化与部署

| 方向 | 说明 |
|------|------|
| **Electron 产品化** | 安装包 / 代码签名 / 自动更新 |
| **MCP 多传输** | stdio 之外增加 SSE / HTTP 传输方式 |
| **多作品隔离** | 单 KSFS 下支持多作品虚拟命名空间 |
| **阿里云部署** | 后端远程部署为多人可用的 API 服务 |

## 五、架构与工程演进

| 方向 | 说明 |
|------|------|
| **EventBus / 观察者模式** | 类型化消息总线，解耦零散通知 |
| **本地大模型接入** | Ollama / LM Studio 替换远程 API 实现完全离线 |
| **Embedding 模型可插拔** | 运行时切换 bge-small / bge-large / m3e / text2vec |
| **RAG 评估 Dashboard** | 基准集自动跑分 + Recall@k / MRR 趋势可视化 |
