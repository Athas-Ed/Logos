# 快速开始

## 环境要求

- **Docker Desktop**（Docker 体验方式）
- 或 **Python 3.11+** + **Node.js 18+**（开发方式）

---

## 🐳 Docker 一键体验（推荐快速试用）

> 无需安装 Python/Node.js，仅需 Docker Desktop。适合演示和面试。

```bash
# Windows — 双击根目录 start.cmd
# 或终端执行：
start.cmd

# macOS / Linux — 终端执行：
chmod +x start.sh && ./start.sh
```

脚本自动完成：生成默认配置 → 构建镜像 → 启动后端+前端 → 打开浏览器。

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端界面 | http://localhost:3000 | Nginx + React |
| 后端 API | http://localhost:8000 | FastAPI（/api 自动代理） |

**无 API Key 时自动使用 LLM 桩后端**（回复带「桩后端」前缀），可零配置体验完整流程。

如需调用真实模型，编辑 `config/local.yaml` 填入 `llm.api_key` 后重启：

```bash
docker compose down && docker compose up -d
```

### 手动控制

```bash
docker compose up -d      # 启动
docker compose down       # 停止
docker compose logs -f    # 跟踪日志
```

## 🛠️ 开发环境启动（适合改代码调试）

> 需要本机安装 **Python 3.11+** 和 **Node.js 18+**。支持 Vite 热重载 + Electron。

### Windows 一键启动

双击 **`scripts\start_logos.cmd`**，自动弹出三个窗口：

| 窗口 | 端口 | 说明 |
|------|------|------|
| Logos Backend | :8000 | Python FastAPI 后端 |
| Logos Vite | :5173 | React + Vite 开发服务器（热重载） |
| Logos Electron | — | 桌面壳（加载 Vite） |

### macOS / Linux / 手动分步

**1. Python 依赖**

```bash
python -m venv .venv
# Windows: .\.venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"

# 验证
pytest -m "not slow"
```

**2. 配置 LLM 密钥（可选）**

```bash
cp config/local.example.yaml config/local.yaml
```

不配置则自动使用 LLM 桩后端。

**3. 启动后端**

```bash
python scripts/run_dev_backend.py
```

**4. 启动前端（新终端）**

```bash
cd src/gui && npm install && npm run dev
```

浏览器打开 **http://localhost:5173**，Vite 自动代理 `/api` 到后端 8000。

**5. （可选）Electron 桌面壳**

```bash
cd src/electron && npm run electron:dev
```

## 健康检查

后端启动后验证：

```bash
curl http://localhost:8000/api/v1/health
# → {"status":"ok"}
```

## 常见问题

| 现象 | 建议 |
|------|------|
| 回复带「桩后端」 | 未配置 `llm.api_key`；属 LLM 桩，非服务未启动 |
| 8000 端口占用 | 关闭重复进程，或设 `LOGOS_ELECTRON_SKIP_BACKEND=1` |
| Electron 安装失败 | `cd src/electron && npm run install:with-mirror`（国内镜像） |
| Docker 构建慢 | 首次构建需下载依赖；后续利用缓存会快很多 |
