# 快速开始

## 环境要求

- **Python** 3.11+
- **Node.js** 18+（GUI / Electron）

## 1. Python 依赖

```bash
python -m venv .venv
# Windows: .\.venv\Scripts\activate
pip install -e ".[dev]"
pytest -m "not slow"
```

---

## 也可用 Docker 运行（仅后端）

无需安装 Python/Node.js，仅需 **Docker Desktop**。

```bash
# 1. 复制配置模板（可选：填写 llm.api_key）
cp config/local.example.yaml config/local.yaml

# 2. 构建并启动（http://localhost:8000）
docker compose up -d

# 3. 查看日志
docker compose logs -f

# 4. 停止
docker compose down
```

Windows 也可用辅助脚本：

```powershell
.\scripts\docker_run.ps1 -d        # 后台启动
.\scripts\docker_run.ps1 --logs    # 启动后跟踪日志
.\scripts\docker_run.ps1 -down     # 停止
```

> 注意：Docker 运行仅包含后端，GUI 仍须通过 `cd src/gui && npm run dev` 单独启动（见第 4 节）。

## 2. 配置密钥（可选）

```bash
cp config/local.example.yaml config/local.yaml
```

填写 `llm.api_key` 后，开发用组合根后端将调用真实模型。

## 3. 一键启动（Windows）

`scripts/start_logos.cmd` 或 `scripts/start_logos.ps1` 会拉起：

| 服务 | 端口 | 说明 |
|------|------|------|
| 开发用组合根后端 | 8000 | `scripts/run_dev_backend.py` |
| Vite GUI | 5173 | `src/gui` |
| Electron | — | 加载 Vite |

## 4. 手动启动

**终端 A：**

```bash
python scripts/run_dev_backend.py
```

**终端 B：**

```bash
cd src/gui && npm install && npm run dev
```

## 5. Electron

先保证 Vite 在 5173 运行，再 `cd src/electron && npm run electron:dev`。详见 [GUI 与桌面壳](子系统文档/GUI与桌面壳.md)。

## 6. 健康检查

- `GET http://127.0.0.1:8000/api/v1/health`
- `GET http://127.0.0.1:8000/api/v1/bootstrap`

## 常见问题

| 现象 | 建议 |
|------|------|
| 回复带「桩后端」 | 未配置 `llm.api_key`；属 LLM 桩，非服务未启动 |
| 8000 占用 | 关闭重复进程或 `LOGOS_ELECTRON_SKIP_BACKEND=1` |
| Electron 安装失败 | `npm run install:with-mirror` |
