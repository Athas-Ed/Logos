# 快速开始

## 环境要求

- **Python** 3.11+
- **Node.js** 18+（GUI / Electron）
- 操作系统：开发脚本以 **Windows** 最完整；macOS / Linux 可用等价命令手动启动

## 1. Python 依赖

在仓库根目录：

```bash
python -m venv .venv
# Windows
.\.venv\Scripts\activate
# macOS / Linux
# source .venv/bin/activate

pip install -e ".[dev]"
pytest -m "not slow"
```

`not slow` 可跳过依赖本机 BGE 嵌入权重的测试。权重目录说明见 `models/README.md`。

## 2. 配置密钥（可选）

```bash
cp config/local.example.yaml config/local.yaml
```

在 `local.yaml` 中填写 `llm.api_key` 等。该文件已忽略提交。详见 [配置说明](配置说明.md)。

## 3. 一键启动（推荐，Windows）

- 双击 `scripts/start_logos.cmd`，或
- 在仓库根执行：`.\scripts\start_logos.ps1`

将依次拉起：

| 服务 | 端口 | 说明 |
|------|------|------|
| 桩后端 | 8000 | `scripts/run_backend_stub.py` |
| Vite GUI | 5173 | `src/gui` 开发服务器 |
| Electron | — | 加载 Vite 页面 |

macOS / Linux：可分别启动后端与 GUI（见下节），Electron 步骤见 [GUI 与桌面壳](子系统文档/GUI与桌面壳.md)。

## 4. 手动启动（后端 + 浏览器）

**终端 A — 后端：**

```bash
python scripts/run_backend_stub.py
```

**终端 B — GUI：**

```bash
cd src/gui
npm install
npm run dev
```

浏览器访问 Vite 地址（默认 `http://127.0.0.1:5173`），`/api` 由 Vite 代理到 `http://127.0.0.1:8000`。

## 5. Electron 开发态

1. 先按上一节保证 **Vite 已在 5173 运行**。
2. 另开终端：

```bash
cd src/electron
npm install          # 国内网络不稳可用 npm run install:with-mirror
npm run electron:dev
```

若后端已由一键脚本启动，请设置 `LOGOS_ELECTRON_SKIP_BACKEND=1` 避免重复占用 8000 端口。

更多环境变量、打包与排障见 [GUI 与桌面壳](子系统文档/GUI与桌面壳.md)。

## 6. 健康检查

- `GET http://127.0.0.1:8000/api/v1/health` → `{"status":"ok"}`
- `GET http://127.0.0.1:8000/api/v1/bootstrap` → 展示档位、Skill 列表、缓存路径等

## 7. GUI E2E（可选）

```bash
cd src/gui
npm install
npx playwright install chromium
npm run test:e2e
```

## 常见问题

| 现象 | 建议 |
|------|------|
| 无 API Key 时回复带「桩」字样 | 正常；配置 `llm.api_key` 后重启后端 |
| Electron 下载失败 | `src/electron` 下执行 `npm run install:with-mirror` |
| 8000 端口被占用 | 关闭重复后端或设置 `LOGOS_ELECTRON_SKIP_BACKEND=1` |
| 检索无结果 | 确认 KSFS 下有 `.md` 实体，必要时触发 HSI/SVS 同步（见 KSFS 文档） |
