# 配置说明

## 文件分工

| 文件 | 是否入库 | 用途 |
|------|----------|------|
| `config/defaults.yaml` | 是 | 默认值，不含密钥 |
| `config/local.example.yaml` | 是 | 复制为 `local.yaml` |
| `config/local.yaml` | **否** | API Key、路径覆盖 |

加载顺序：`defaults.yaml` → `local.yaml` → 可选 `LOGOS_*` 环境变量。

## 开发用组合根后端（Development backend）

在仓库根执行：

```bash
python scripts/run_dev_backend.py
```

启动本地 **FastAPI + Uvicorn**（`http://127.0.0.1:8000`），即 GUI / Electron 使用的 **开发用组合根后端**：

- 读取 `config/`，构造 **`AppPorts`**（LLM、检索、KSFS、MCP、开发者开关等）。
- 已配置 `llm.api_key` → **OpenAI 兼容**远程模型；未配置 → LLM 使用**内存桩**（回复带「桩后端」前缀，便于辨认）。
- 可装配 HSI/SVS/Chroma（`pip install -e ".[dev]"`）与 `skills.mcp_servers`。
- `scripts/start_logos.ps1` / `.cmd` 默认也会拉起该进程。

脚本文件名中的 **stub** 仅指「无 Key 时的 LLM 桩实现」，**不是**「整个后端是假的」。

## 大模型（OpenAI 兼容）

在 `config/local.yaml` 中配置 `llm.api_key`、`base_url`、`model` 等。详见 `local.example.yaml`。

## Agent / ReAct 步数

`config/defaults.yaml` 中 `agent.react`：

| 键 | 默认 | 含义 |
|----|------|------|
| `max_steps` | `16` | **ReAct 范式**通用步数上限（`lint_zh` 等按 manifest 使用 `react` 的 Skill） |
| `max_QA_steps` | `20` | **检索问答**（`retrieve_qa`）专用：按**每个 user 问题**计一轮 ReAct 迭代次数 |

- 步数指单轮 ReAct 循环内 LLM 迭代次数（含工具调用步），非「会话内总轮数」。
- 触顶后服务端做收束 synthesis，SSE `done` 带 `react_hit_step_limit: true`；**无**续跑 / `react_resume_messages`。
- 可在 `local.yaml` 覆盖，例如 `agent.react.max_QA_steps: 30`。

## UI / 连续问答

| 键 | 默认 | 含义 |
|----|------|------|
| `ui.SSE_maxNum` | `3` | 后台 SSE 并发上限 |
| `ui.cache_warn_bytes` | `524288000` | 会话缓存占用告警阈值 |
| `ui.max_history_full_text` | `5` | 连续问答时 CB 保留最近几轮 user/assistant **全文** |

`bootstrap.ui` 会下发 `react_max_steps`、`react_max_qa_steps` 等供 GUI 对齐（见 [HTTP API 概览](子系统文档/HTTP-API概览.md)）。
