# 配置说明

## 文件分工

| 文件 | 是否入库 | 用途 |
|------|----------|------|
| `config/defaults.yaml` | 是 | 默认值，不含密钥 |
| `config/local.example.yaml` | 是 | 复制为 `local.yaml` |
| `config/local.yaml` | **否** | API Key、路径覆盖 |

加载顺序：`defaults.yaml` → `local.yaml` → 可选 `LOGOS_*` 环境变量。

## 开发用组合根后端（Development backend）

在仓库根执行：

```bash
python scripts/run_backend_stub.py
```

启动本地 **FastAPI + Uvicorn**（`http://127.0.0.1:8000`），即 GUI / Electron 使用的 **开发用组合根后端**：

- 读取 `config/`，构造 **`AppPorts`**（LLM、检索、KSFS、MCP、开发者开关等）。
- 已配置 `llm.api_key` → **OpenAI 兼容**远程模型；未配置 → LLM 使用**内存桩**（回复带「桩后端」前缀，便于辨认）。
- 可装配 HSI/SVS/Chroma（`pip install -e ".[dev]"`）与 `skills.mcp_servers`。
- `scripts/start_logos.ps1` / `.cmd` 默认也会拉起该进程。

脚本文件名中的 **stub** 仅指「无 Key 时的 LLM 桩实现」，**不是**「整个后端是假的」。

## 大模型（OpenAI 兼容）

在 `config/local.yaml` 中配置 `llm.api_key`、`base_url`、`model` 等。详见 `local.example.yaml`。

## 路径类

| 键 | 含义 |
|----|------|
| `ksfs_root` | KSFS 根 |
| `workspace_root` | 工作区 |
| `CONVERSATIONS_CACHE` | 档 B 会话 JSON 目录 |

## MCP Skill

见 [Skills 与 MCP 扩展](子系统文档/Skills与MCP扩展.md) 与 `local.yaml` 中 `skills.mcp_servers`。

## 本地数据目录（不入库）

| 目录 | 用途 |
|------|------|
| `resources/ksfs/` | 个人 KSFS 实体 |
| `workspace/` | 草稿、会话 JSON |
| `example_ksfs/` | 开发示例 KSFS |
| `.index/` | 索引（可重建） |

## 隐私

分享仓库前确认未提交 `local.yaml` 或私人 `.md`。
