# 配置说明

## 文件分工

| 文件 | 是否入库 | 用途 |
|------|----------|------|
| `config/defaults.yaml` | 是 | 默认路径、UI 阈值、Obs 档位等 |
| `config/local.example.yaml` | 是 | 本机配置模板（复制后改名） |
| `config/local.yaml` | **否**（`.gitignore`） | API Key、代理、路径覆盖 |

**不要**将密钥提交到 Git。若曾误提交，请轮换 Key 并从历史中清除。

## 大模型（OpenAI 兼容）

在 `config/local.yaml` 中示例：

```yaml
llm:
  api_key: "sk-..."
  base_url: "https://api.deepseek.com/v1"
  model: "deepseek-chat"
```

未配置或设置环境变量 `LOGOS_FORCE_STUB_LLM=1` 时，后端使用桩回复（便于无网开发）。`GET /api/v1/bootstrap` 的 `llm_mode` 字段可区分 `stub` / `remote`。

## 路径类

常用项（可在 `local.yaml` 的 `paths:` 下覆盖）：

| 键 | 含义 |
|----|------|
| `ksfs_root` | KSFS 叙事知识根目录 |
| `workspace_root` | 工作区（草稿、`setting_entry/`） |
| `hsi_sqlite_path` | HSI 元数据库 |
| `vector_index_path` | Chroma 向量库目录 |

相对路径均相对于**仓库根**解析。

## MCP Skill

在 `local.yaml` 的 `skills.mcp_servers` 中声明 stdio 入口，例如：

```yaml
skills:
  mcp_servers:
    - id: example_echo
      enabled: true
      entrypoint: skills/example-stdio-mcp/server.py
```

详见 [Skills 与 MCP 扩展](子系统文档/Skills与MCP扩展.md)。

## UI 与缓存告警

`defaults.yaml` 中 `ui.cache_warn_bytes` 控制会话缓存体积告警阈值；`ui.SSE_maxNum` 限制并发 SSE 数。GUI 启动时从 bootstrap 读取。

## 日志

- 根目录默认 `logs/`，分 `daily/`（日常）与 `maint/`（维护）。
- `obs.log_profile` 控制详细程度。
- 运行时 `*.log` 不入库。

## 隐私与创作数据

- `workspace/`、`.index/` 默认已忽略，适合存放个人稿件与索引。
- 对外分享仓库前请确认未附带 `local.yaml` 或私有 KSFS 内容。
