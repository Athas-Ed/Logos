# Logos V0.1 快速启动

规格全文见仓库根目录 `original_docs/SPEC-V0.1.md`，并行分工见 `original_docs/DEVPLAN-V0.1-PARALLEL.md`。

## 1. Python 与依赖

```bash
cd /path/to/Logos
python -m venv .venv
# Windows: .\.venv\Scripts\activate
# Unix:    source .venv/bin/activate
pip install -e ".[dev]"
pytest
```

## 2. 后端（I&I）

V0.1 的完整 `AppPorts` 装配可随 Stream 演进；本地联调 GUI 可使用**桩后端**（真实读取 `config/`，LLM/向量等为内存桩）：

```bash
python scripts/run_backend_stub.py
```

默认监听 `http://127.0.0.1:8000`，提供 `GET /api/v1/health` 与 `POST /api/v1/chat`（SSE）。

## 3. 前端（GUI）

另开终端：

```bash
cd src/gui
npm install
npm run dev
```

Vite 将 `5173` 端口上的 `/api` 代理到 `http://127.0.0.1:8000`（可用环境变量 `VITE_DEV_API_PROXY_TARGET` 覆盖）。

## 4. 一键脚本

- **Windows（推荐）**：在资源管理器中双击 `scripts/start_logos.cmd`，或在仓库根执行  
  `powershell -ExecutionPolicy Bypass -File scripts/start_logos.ps1`
- **macOS / Linux**：`chmod +x scripts/start_logos.sh && ./scripts/start_logos.sh`
- 旧名称 `scripts/run_dev.ps1` / `run_dev.sh` 仍会转调上述逻辑。

## 5. Stream 7（S&G）

- `write_draft` 工具通过 `logos.harness.sg_layer` 路径沙箱写入，禁止逃出 `paths.workspace_root`。
- 示例 stdio 子进程：`skills/example-stdio-mcp/echo_worker.py`（供 MCP 起停类测试参考）。
