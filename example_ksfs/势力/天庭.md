# 天庭

## 概况
天庭是三界最高统治机构，由玉皇大帝统御，掌管天、地、人三界秩序。天庭位于三十三重天之上，宫阙林立，云雾缭绕。

## 主要成员
- **玉皇大帝**：三界至尊，历一千七百五十劫，每劫十二万九千六百年
- **王母娘娘**：天庭女仙之首，掌管蟠桃
- **太上老君**：道教始祖，居兜率宫，炼九转金丹，制无数法宝
- **太白金星**：玉帝近臣，主招安议和，曾两度招安孙悟空
- **二郎神**：玉帝外甥，三尖两刃刀，八百度天眼，曾擒拿孙悟空
- **四大天王**：镇守南天门
- **托塔天王李靖** + **哪吒三太子**：天庭统兵大员

## 与孙悟空的关系
天庭与孙悟空的关系经历了"招安→反叛→镇压→再到招安"的循环：
1. 太白金星招安孙悟空上天做弼马温
2. 悟空嫌官小，反下天庭，自封齐天大圣
3. 再次招安看管蟠桃园，却大闹蟠桃会
4. 十万天兵捉拿不得，二郎神擒获后入八卦炉
5. 悟空破炉而出大闹天宫，无人能敌
6. 如来佛祖出面，压悟空于五行山下
7. 取经路上，天庭多次协助收妖

## 蟠桃
天庭蟠桃园有三千六百株桃树，分三千年、六千年、九千年三种品阶，食之可成仙、长生、与天地同寿。
