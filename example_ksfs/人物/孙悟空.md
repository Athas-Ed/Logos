# 孙悟空

## 身份
东胜神洲傲来国花果山灵石所生，拜菩提祖师为师，得名孙悟空。后大闹天宫，被如来佛祖镇压于五行山下五百年，后保护唐僧西天取经，终成斗战胜佛。

## 外貌
尖嘴缩腮，毛脸雷公嘴，身高不足四尺，目运金光。身穿锁子黄金甲（早年），头戴凤翅紫金冠（早年），取经时着僧衣虎皮裙。

## 性格
桀骜不驯，机敏聪慧，嫉恶如仇，忠义护师。平日嬉笑怒骂，临阵时智勇双全。

## 能力
- **七十二变**：地煞数变化，可化飞禽走兽、草木山石
- **筋斗云**：一个筋斗十万八千里
- **金刚不坏之躯**：太上老君八卦炉中炼就，刀枪不入
- **火眼金睛**：八卦炉烟熏而成，可辨妖邪真身
- **法天象地**：施展时身高万丈

## 兵器
- **如意金箍棒**：原是天河定底神珍铁，大禹治水时所用，重一万三千五百斤，可随心意变化大小

## 经历简述
1. 花果山称王 → 访仙学道 → 龙宫得宝 → 地府销名
2. 齐天大圣 → 大闹天宫 → 八卦炉炼 → 五行山下
3. 随唐僧西行 → 三打白骨精 → 真假美猴王 → 三借芭蕉扇
4. 历经九九八十一难 → 功德圆满 → 封斗战胜佛
