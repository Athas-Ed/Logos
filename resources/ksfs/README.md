# KSFS 知识库根（`paths.ksfs_root`）

本目录为 **叙事知识唯一事实源** 的默认位置；**个人 `.md` 稿默认被 `.gitignore`**（勿将创作内容提交到公开仓库）。

- 约定全文见 **`original_docs/重要子系统开发文档/KSFS开发.md`**
- 仓库内**可提交**的样例树仍可使用根目录 **`example_ksfs/`**（跑测试与演示）

**`.index/`（默认在仓库根，已 gitignore）**：仅应出现 **`.high-speed_index`**（HSI）与 **`.vector_index/`**（向量库）。历史遗留的杂目录可手动删除后重建索引。
